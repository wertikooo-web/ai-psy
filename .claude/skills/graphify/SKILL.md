# Skill: graphify-reference

## Описание

Graphify (https://github.com/wertikooo-web/graphify) — Python-инструмент, который превращает код, SQL-схемы, документы и медиа в queryable knowledge graph. Проект YC S26, MIT-лицензия.

**Стек**: Python, Tree-sitter, Faster-whisper, MCP-сервер, бэкенды Claude / OpenAI / Gemini / DeepSeek, вывод в HTML / JSON / Mermaid / Neo4j.

Этот skill включается когда в ai-psy (Next.js, TypeScript) нужно:
- выбрать архитектурный паттерн,
- добавить новый тип интеграции (LLM, MCP, транскрипция),
- смоделировать данные клиента или историю консультаций,
- принять решение по провайдер-абстракции.

---

## Когда использовать Graphify как референс

### 1. LLM-провайдер абстракция
Graphify поддерживает Claude / OpenAI / Gemini / DeepSeek через единый интерфейс с runtime-переключением. Использовать как референс, когда в ai-psy нужно:
- добавить нового провайдера в `lib/llm/`,
- изменить схему fallback между провайдерами,
- принять решение о формате конфига провайдера.

**Проверить в Graphify**: как устроен provider-router, как передаётся model/provider в вызов, как обрабатываются ошибки конкретного бэкенда.

### 2. MCP-интеграция
Graphify реализует MCP stdio/HTTP-сервер. Использовать как референс, когда в ai-psy появится задача:
- добавить MCP-эндпоинт для доступа к консультациям / клиентам,
- выставить AI-анализ как MCP-инструмент для других агентов.

**Проверить в Graphify**: структуру MCP-инструментов, формат schema для tool definitions, обработку streaming.

### 3. Транскрипция и обработка медиа
Graphify использует Faster-whisper для аудио/видео. ai-psy использует OpenAI Whisper API. Использовать как референс, когда нужно:
- добавить поддержку локальной транскрипции (без API),
- выбрать стратегию chunking для длинных записей,
- принять решение по language detection.

### 4. Моделирование знаний / история клиента
Graphify строит knowledge graph с relationship extraction и confidence scoring. Использовать как концептуальный референс, когда в ai-psy нужно:
- улучшить `assembleClientContext()` — добавить граф связей между темами клиента,
- продумать структуру `client-history.json` для хранения паттернов,
- добавить автоматическую экстракцию ключевых тем из транскриптов.

**Не переносить** граф-движок в ai-psy без явного запроса — это избыточно для текущего MVP.

### 5. Визуализация / HTML-вывод
Graphify генерирует интерактивные HTML-визуализации графов. Использовать как референс, когда в ai-psy нужна:
- визуализация динамики клиента по сессиям,
- граф связей между темами / гипотезами.

## Правила применения

1. **Сначала проверить** — перед созданием нового паттерна в ai-psy проверить, есть ли аналогичное решение в Graphify.
2. **Предлагать перенос только если упрощает** — если решение из Graphify добавляет зависимость или сложность без ощутимой пользы для текущего MVP, не переносить.
3. **Не менять стек ai-psy** — Graphify на Python; ai-psy на TypeScript/Next.js. Переносятся только паттерны и концепции, не код.
4. **Фиксировать что взято** — если архитектурное решение вдохновлено Graphify, кратко упомянуть это в PR-описании или комментарии к задаче.

## Когда этот skill НЕ применяется

- Правка UI-компонентов, стилей, Tailwind — Graphify не имеет UI-библиотеки.
- Работа с flat-file JSON store (consultations.json и т.д.) — Graphify использует граф-БД, прямой аналогии нет.
- Hotfixes и мелкие баги — нет смысла проверять референс для точечных правок.
