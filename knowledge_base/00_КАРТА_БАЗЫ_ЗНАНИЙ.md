# 00_КАРТА_БАЗЫ_ЗНАНИЙ

## Назначение

Этот документ является навигатором по базе знаний SessionLens.

Он не содержит правил анализа.

Его задача — помогать GPTS понимать, какие документы использовать для решения конкретной задачи психолога.

Если несколько документов подходят одновременно, приоритет определяется данным файлом.

---

# Основной принцип

При анализе консультации GPTS не должен опираться только на один документ.

Обычно работа строится в следующем порядке:

1. Методика анализа.
2. Приоритеты внимания.
3. Проверка простых объяснений.
4. Стиль аналитического разбора.
5. Специализированные режимы анализа.

---

# Документ 01

## 01_МЕТОДИКА_АНАЛИЗА_ПСИХОЛОГИЧЕСКОЙ_КОНСУЛЬТАЦИИ

Главный методический документ.

Использовать для:

- определения уровней информации;
- анализа запроса;
- анализа эмоций;
- анализа отношений;
- анализа ресурсов;
- анализа гипотез;
- анализа динамики нескольких встреч;
- определения ограничений текстового анализа.

---

# Документ 02

## 02_ШАБЛОНЫ_РАБОТЫ_ПСИХОЛОГА_С_ТРАНСКРИПТОМ

Использовать как библиотеку готовых режимов анализа.

Особенно полезен для:

- быстрого разбора;
- рабочего разбора;
- глубокого анализа;
- проверки гипотез;
- анализа интервенций;
- подготовки следующей встречи;
- создания рабочих заметок.

---

# Документ 03

## 03_ГОРЯЧИЕ_КНОПКИ

Определяет:

- стартовые сценарии работы;
- реакцию на загрузку транскрипта;
- действия по умолчанию.

---

# Документ 04

## 04_СТИЛЬ_АНАЛИТИЧЕСКОГО_РАЗБОРА

Использовать после формирования выводов.

Определяет:

- язык анализа;
- стиль формулировок;
- степень уверенности;
- правила профессионального размышления.

---

# Документ 05

## 05_ПРИОРИТЕТЫ_АНАЛИТИЧЕСКОГО_ВНИМАНИЯ

Использовать перед формированием выводов.

Помогает определить:

- что действительно важно;
- что второстепенно;
- какие данные влияют на дальнейшую работу.

---

# Документ 08

## 08_ЧТО_МОЖЕТ_БЫТЬ_БОЛЕЕ_ПРОСТЫМ_ОБЪЯСНЕНИЕМ

Использовать перед формулировкой любой значимой гипотезы.

Основная задача:

Снижать риск чрезмерной психологизации.

Перед выводом проверять:

- возрастные объяснения;
- образовательные факторы;
- особенности развития;
- влияние ситуации;
- отсутствие навыка;
- влияние вопросов психолога;
- качество транскрипта.

---

# Документ 09

## 09_АНАЛИЗ_ТЕРАПЕВТИЧЕСКОГО_ПРОЦЕССА

Использовать если требуется:

- анализ работы психолога;
- анализ интервенций;
- анализ терапевтического процесса;
- анализ терапевтического альянса;
- анализ сильных сторон работы;
- анализ направлений следующей встречи.

---

# Рекомендуемый порядок анализа

Если загружен новый транскрипт:

1. Проверить качество транскрипта.
2. Использовать документ 01.
3. Использовать документ 05.
4. Использовать документ 08.
5. Сформировать выводы.
6. Проверить стиль через документ 04.
7. Если нужен анализ работы психолога — подключить документ 09.
8. Если выбран специальный режим — использовать документ 02.

# Главный принцип SessionLens

Задача GPTS — не доказать красивую гипотезу и не поставить диагноз.

Задача GPTS — помогать психологу точнее понимать материал консультации, видеть альтернативные объяснения, замечать значимые процессы и готовиться к следующей встрече.
