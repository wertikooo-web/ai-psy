## Проект

**TRANSCRIPT AI · PSY** — рабочее пространство психолога.  
Next.js 15.5 / React 19 / TypeScript / Tailwind / Supabase / Railway / OpenAI.

Суть: загружаешь аудио или транскрипт консультации → получаешь AI-анализ → ведёшь чат с AI по сессии → накапливаешь историю клиента.

---

## Инфраструктура (всё работает в проде)

- **Railway** — автодеплой из ветки `main`. Push в `main` = деплой.
- **Supabase** — production БД (service role key). Одиночный пользователь.
- **OpenAI** — GPT-4o для анализа и чата, Whisper для транскрибации аудио.
- **Git-стратегия**: разработка на `ai-dev`, merge `--no-ff` в `main`, push.

## Что полностью готово и работает

### Клиенты
- Создание клиента (имя, аватар, цвет, запрос)
- При создании запрос автоматически пишется в `client_requests` — сразу виден в карточке и на главной
- Список клиентов на главной с аватаром, запросом, датой последней сессии
- Карточка клиента с вкладками: Обзор / Запрос / Консультации / История / Материалы / Наблюдения

### Консультации
- Загрузка через 3 источника: аудио (mp3/m4a/wav → Whisper), готовый транскрипт (txt/md/вставка текста), текстовые заметки
- Список консультаций с датой, статусом, кнопками удаления (всегда видна красная корзина)
- Страница консультации: три колонки (Транскрипт / AI-анализ / Чат), каждая прокручивается независимо, фиксированная высота тулбаров (`--consultation-toolbar-height: 36px`)

### Транскрипт (левая колонка)
- Вкладки: Транскрипт / Заметки / Материалы
- Кнопка **+ Добавить** в правой части тулбара:
  - Транскрипт → открывает UploadModal (выбор источника)
  - Заметки → форма добавления наблюдения прямо в колонке, сохранённые наблюдения отображаются сразу (с датой)
  - Материалы → ImportMaterialModal
- Экспорт транскрипта: TXT / PDF / Word (.docx) / Markdown

### AI-анализ (средняя колонка)
- Режимы: Рабочий / Глубокий / Гештальт / Процесс терапевта
- Кнопка **+ АНАЛИЗ** запускает анализ
- При устаревших данных: строка `* Данные изменились — обновите анализ` над текстом анализа (курсив, не баннер)
- Экспорт анализа: TXT / PDF / Word / Markdown (выпадающее меню)

### Чат (правая колонка)
- Контекстный AI-чат по текущей сессии (транскрипт + анализ + история клиента в системном промпте)
- Быстрые фразы: **динамические** (2–3 чипа, генерирует gpt-4o-mini по транскрипту+анализу+чату, фиолетовые) + **статические** (4 фиксированных, синие)
- Клик на чип → сразу отправляет (не заполняет textarea)
- Чип-сообщения отображаются в чате как пилюля, а не синий пузырь
- AI-ответы группируются в абзацы по 2 предложения, не одно предложение = одна строка
- Кнопка **Сохранить** → сохраняет ключевые выводы чата в историю клиента
- GPTS-ссылка на внешний GPT

### История клиента
- Структурированные блоки: темы, гипотезы, ресурсы, события, что исследовали, уточнения, заметки
- Накапливается из сохранённых чатов

### Материалы клиента
- Наблюдения, заметки, импортированные файлы
- cross-component события: `observation-created`, `material-added`

### Экспорт
- Транскрипт: TXT, PDF (window.print), Word (docx пакет v9.7.1), Markdown
- Анализ: те же 4 формата
