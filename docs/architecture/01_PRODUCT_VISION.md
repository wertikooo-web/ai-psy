# 01 — Product Vision

## Что это за продукт

Transcript AI PSY — инструмент для психологов, который превращает сырые записи сессий (аудио, транскрипты, заметки) в структурированные AI-анализы.

Цель: не заменить психолога, а снять с него когнитивную нагрузку по структурированию и документированию случая.

## Ключевые принципы

**История не удаляется.**
Ни запрос клиента, ни старые анализы, ни чаты не затираются при появлении новых данных. Вся работа — это накапливаемый след.

**Контекст передаётся явно.**
AI не "знает" клиента магическим образом. Он получает ровно тот контекст, который психолог накопил в системе. Это делает поведение AI предсказуемым и аудируемым.

**Психолог управляет, AI помогает.**
AI предлагает гипотезы, замечает паттерны, структурирует. Психолог принимает решения.

## Целевая аудитория

Практикующий психолог / психотерапевт:
- ведёт 10–30 клиентов одновременно
- делает записи после каждой сессии или пишет транскрипты
- хочет видеть динамику случая во времени
- не хочет тратить 40 минут на написание заметок после каждой встречи

## Не входит в продукт

- Видеосвязь с клиентом
- Назначение встреч / расписание
- Выставление счетов
- Медицинская документация (не EMR)

## Дорожная карта (крупные вехи)

| Версия | Фокус |
|--------|-------|
| v1 (текущая) | Транскрипция + AI-анализ + история клиента |
| v2 | История запросов клиента + динамика случая |
| v3 | Мультитенант / SaaS + приватность |
| v4 | Экспорт случая + супервизия |
