# Руководство пользователя TRANSCRIPT AI · PSY

Версия документа: 1 ноября 2026. Основано на исходном коде приложения. Интерфейс может немного отличаться в конкретной сборке.

## Что это за программа
Рабочее пространство психолога: карточки клиентов, консультации, аудиозаписи и транскрипты, AI-разбор сессий, чат с контекстом и история работы с клиентом.

## Первое открытие
1. Откройте развернутый адрес приложения. Для локальной установки используется http://localhost:3000.
2. Перейдите в **Настройки** (`/settings`). Заполните профессиональный профиль, проверьте раздел AI и выбранную модель.
3. Откройте **Помощь** (`/help`): там есть индикаторы доступности OpenAI, базы знаний и Whisper.
4. Если сервисы не настроены, передайте разработчику инструкцию `README.md` и `docs/CLIENT_HANDOFF.md`. Не вводите секретный OpenAI ключ в публичные сообщения.

## Сценарий №1. Добавить клиента
1. Откройте **Клиенты** (`/clients`).
2. Нажмите **Добавить клиента**.
3. Укажите имя и, при необходимости, исходный запрос.
4. Откройте карточку созданного клиента. В ней есть вкладки **Запрос**, **Консультации**, **История** и **Материалы**.

**Запрос** — с чем человек пришёл и как меняется рабочий фокус. **История** — хронология событий и наблюдений. **Материалы** — документы и дополнительные тексты, которые могут быть полезны в последующих разборах.

## Сценарий №2. Создать консультацию
Откройте **Консультации** (`/consultations`) либо карточку нужного клиента и выберите действие для добавления записи. В окне загрузки сначала выбирается клиент, затем один из трёх источников:

- **Аудиозапись**: поддерживаются, в частности, MP3, M4A, WAV, OGG, WebM. Загрузите файл и создайте консультацию, затем запустите транскрибацию.
- **Готовый транскрипт**: загрузите TXT/MD или вставьте текст вручную. Можно сразу переходить к анализу.
- **Текстовые заметки**: запишите наблюдения специалиста. Это отдельный тип материала, который не следует путать с дословной стенограммой.

Обратите внимание: для больших аудиофайлов сервер использует FFmpeg, а распознавание речи зависит от доступности OpenAI API.

## Сценарий №3. Работать с консультацией
Откройте запись из списка. Рабочая страница рассчитана на три панели:

1. **Транскрипт** — текст консультации, при наличии форматированный по репликам.
2. **AI-анализ** — выбор режима и получение гипотез и наблюдений.
3. **Чат** — вопросы по текущей консультации и уточнение выводов.

Режимы анализа в коде: **рабочий**, **глубокий**, **анализ процесса психолога** (+A), **гештальт** (+G). Проверяйте выводы AI самостоятельно: модель может ошибаться и не должна подменять профессиональное решение.

## Сценарий №4. Вернуться к предыдущей работе
В карточке клиента откройте **Консультации**, выберите прошедшую сессию, затем сверяйте результаты с вкладками **История** и **Материалы**. Для нового запроса можно вести отдельную хронологию работы.

## Что есть ещё
В коде присутствуют календарь, заметки, аналитика, профессиональный профиль и интеграция Telegram. Наличие страниц и модулей не означает, что каждая функция уже прошла end-to-end тесты в новой установке.

## Тестовый проход для нового разработчика
Создайте вымышленного клиента, внесите короткий пример транскрипта, запустите анализ, задайте вопрос в чате, проверьте сохранность после перезапуска приложения. Только после этого тестируйте загрузку короткого синтетического аудио.

## Частые проблемы
- **Не видны клиенты**: проверьте доступность Supabase и переменные окружения; пустой список может означать пустую новую базу.
- **Не запускается анализ**: проверьте `OPENAI_API_KEY`, баланс API и раздел Помощь.
- **Не загружается аудио**: проверьте ограничения файла, FFmpeg и приватный bucket `audio` в Supabase Storage.
- **Данные пропали после перезапуска**: приложение могло использовать локальное JSON-хранилище на временном диске вместо Supabase.
- **Страница открывается без входа**: в исходном MVP авторизация не завершена. Не публикуйте экземпляр с чувствительными данными до исправления.
